Semestre 5 · Coloration IA

Application mobile de reconnaissance faciale

SAÉ S5.01 — Deep Learning · Computer Vision · Android

Prédiction d'âge, de genre et d'ethnicité par IA

Projet fil rouge du semestre 5 mené en équipe de trois (Ryan Maria Paul, Ivan Veljovic Bulatovic, Mathew Prades). L'objectif : concevoir, entraîner et intégrer dans une application Android des modèles de deep learning capables de prédire l'âge, le genre et l'ethnicité d'une personne à partir d'une photo de son visage.

Le projet s'est déroulé en deux grandes phases : la construction de modèles « from scratch » avec des CNN en TensorFlow/Keras, puis l'utilisation du transfer learning à partir de modèles pré-entraînés (EfficientNetB0, MobileNetV2, ResNet50). Un modèle triple à sorties multiples (âge + genre + ethnicité depuis une seule entrée) a finalement été intégré à l'application. Résultats du meilleur modèle from scratch : genre ~91,2% d'accuracy, ethnicité ~81%, MAE âge ~5,2 ans.

L'application Android (Kotlin) embarque les modèles via TensorFlow Lite, intègre YOLO pour la détection de visage avant l'inférence, Firebase pour l'authentification et la persistance des données, et propose un mode de prédiction temps réel via le flux caméra. Le projet a été géré de façon agile via Jira et GitHub (branches feature → develop → main, Pull Requests).

Python TensorFlow / Keras Transfer Learning CNN EfficientNetB0 MobileNetV2 Kotlin / Android TensorFlow Lite YOLO Firebase Jira ↗ GitHub

Semestre 6 · Coloration IA

Chatbot RAG de recettes de cuisine

SAÉ S6.01 — RAG · LLM · Angular · Flask · Docker · Render

Application web de chatbot conversationnel spécialisé

Projet fil rouge du semestre 6, mené en équipe de quatre (Ryan Maria Paul, Ivan Veljovic Bulatovic, Mathew Prades, Inès Marcisz). L'objectif : développer et déployer une application web complète de chatbot intelligent spécialisé dans les recettes de cuisine, reposant sur une architecture RAG (Retrieval-Augmented Generation) combinant recherche sémantique et génération par LLM.

L'architecture est découpée en trois couches : un frontend Angular (TypeScript, SPA, modules auth / chat / historique), une API REST Flask (Python) gérant l'authentification JWT + bcrypt, la gestion des conversations et le pipeline RAG, et une double base PostgreSQL — applicative pour les utilisateurs et conversations, documentaire pour les chunks et métadonnées PDF. L'index vectoriel FAISS est chargé en mémoire au démarrage du serveur.

Le pipeline RAG ingère des fichiers PDF découpés en chunks de 512 tokens (chevauchement de 50), génère leurs embeddings et les indexe dans FAISS. À chaque requête, le système récupère les passages les plus proches sémantiquement et construit un prompt enrichi (contexte documentaire + historique) envoyé au LLM via OpenRouter, avec stratégie de fallback entre DeepSeek V4 Flash, Llama 3.3 70B et un modèle gratuit. La réponse est streamée token par token via SSE. L'application est conteneurisée avec Docker (build multi-stage) et déployée sur Render, gérée en agile via Jira et GitHub (branches feature → develop → main, Pull Requests).

Angular · TypeScript Flask · Python RAG FAISS LLM · OpenRouter PostgreSQL JWT · bcrypt SSE streaming Docker Render Jira
