Stage — Veolia Water IS

Janv. – Mars 2025 · 8 semaines
Développeur web — Cellule Technique DSI

Mission principale : développer une application web full-stack permettant de requêter et de consulter les métadonnées d'une GED (Gestion Électronique de Documents) interne.

Architecture mise en place : Elasticsearch comme moteur de recherche distribuée et d'indexation des documents de la GED, une API REST FastAPI (Python) exposant les endpoints de recherche et de filtrage, et un frontend Angular consommant l'API via des requêtes HTTP pour afficher les résultats et permettre l'interaction utilisateur.

FastAPI Python Elasticsearch Angular API REST GED
